# ai-vs-human-text
A competition submission to build a machine learning classifier that predicts whether a given passage was written by a human or generated by AI.

## Competition

[Cornell Tech CS 5785 (2026): AI vs. Human Text](https://www.kaggle.com/competitions/cornell-tech-cs-5785-combined-2026-ai-vs-human-text/overview) on Kaggle.
